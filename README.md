# 🎭 Projeto Divertidamente - Emoções Interativas

Este é um projeto interativo inspirado no filme **Divertidamente (Inside Out)**, criado com **HTML**, **CSS** e **JavaScript**. Ao clicar em cada emoção, o fundo da página muda, aparece uma imagem e uma frase relacionada à emoção, criando uma experiência visual divertida e educativa.

---

## 🧠 Emoções incluídas:

- 😄 **Alegria**
- 😢 **Tristeza**
- 😡 **Raiva**
- 😨 **Medo**
- 😒 **Nojinho**
- 💚 **Inveja** (do Divertidamente 2)
- 😊 Vergonha (do Divertidamente 2)
- 😣 Ansiedade (do Divertidamente 2)
- 😴 Tédio (do Divertidamente 2)

---

## 📸 Funcionalidades:

- Botões interativos para cada emoção.
- Alteração do fundo da página com base na emoção.
- Exibição de imagem e frase personalizada para cada emoção.
- Animações suaves e efeitos visuais ao clicar nos botões.
- Destaque visual no botão da emoção selecionada.

---

## 🎨 Tecnologias usadas:

- `HTML5`
- `CSS3`
- `JavaScript`
